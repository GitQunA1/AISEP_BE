# Table Descriptions

| No | Table | Description |
|----|-------|-------------|
| 01 | **users** | Stores all user accounts in the system (Startup founders, Investors, Advisors, Admin). Inherits from ASP.NET Identity (includes email, password hash, phone number, etc.). <br> - Primary keys: `Id` <br> - Foreign keys: _(none)_ |
| 02 | **roles** | ASP.NET Identity roles table. Stores system roles (e.g., Startup, Investor, Advisor, Admin). <br> - Primary keys: `Id` <br> - Foreign keys: _(none)_ |
| 03 | **user_roles** | Many-to-many mapping between users and roles (ASP.NET Identity). <br> - Primary keys: `UserId`, `RoleId` <br> - Foreign keys: `UserId` → `users(Id)`, `RoleId` → `roles(Id)` |
| 04 | **user_claims** | Stores claim information associated with users (ASP.NET Identity). <br> - Primary keys: `Id` <br> - Foreign keys: `UserId` → `users(Id)` |
| 05 | **user_logins** | Stores external login providers for users (ASP.NET Identity). <br> - Primary keys: `LoginProvider`, `ProviderKey` <br> - Foreign keys: `UserId` → `users(Id)` |
| 06 | **user_tokens** | Stores user authentication tokens (ASP.NET Identity). <br> - Primary keys: `UserId`, `LoginProvider`, `Name` <br> - Foreign keys: `UserId` → `users(Id)` |
| 07 | **role_claims** | Stores claims associated with roles (ASP.NET Identity). <br> - Primary keys: `Id` <br> - Foreign keys: `RoleId` → `roles(Id)` |
| 08 | **startups** | Stores detailed profile information for startup companies registered in the system, including company info, industry, development stage, financials, and team details. <br> - Primary keys: `StartupId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 09 | **investors** | Stores detailed profile information for investors, including organization name, investment preferences, risk tolerance, focus industry, and preferred investment stage. <br> - Primary keys: `InvestorId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 10 | **advisors** | Stores detailed profile information for advisors/consultants, including bio, expertise, certifications, rating, languages spoken, and location. <br> - Primary keys: `AdvisorId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 11 | **projects** | Stores investment projects created by startups. Each project belongs to one startup and can have multiple documents, AI analyses, and deals. <br> - Primary keys: `ProjectId` <br> - Foreign keys: `StartupId` → `startups(StartupId)` |
| 12 | **documents** | Stores uploaded documents (pitch decks, financial reports, legal docs, etc.) associated with a project. Supports blockchain hash verification and IP protection flag. <br> - Primary keys: `DocumentId` <br> - Foreign keys: `ProjectId` → `projects(ProjectId)` |
| 13 | **startup_ai_analyses** | Stores AI-generated analysis results for startup projects, including potential score, chaos score, and detailed analysis JSON. <br> - Primary keys: `EvaluationId` <br> - Foreign keys: `ProjectId` → `projects(ProjectId)` |
| 14 | **investor_ai_analyses** | Stores AI-generated analysis results matching an investor's profile against a specific project. <br> - Primary keys: `AnalysisId` <br> - Foreign keys: `InvestorId` → `investors(InvestorId)`, `ProjectId` → `projects(ProjectId)` |
| 15 | **connectionrequests** | Stores connection requests sent by investors to startups. Tracks status (Pending/Accepted/Rejected), messages, and response details. <br> - Primary keys: `ConnectionRequestId` <br> - Foreign keys: `InvestorId` → `investors(InvestorId)`, `StartupId` → `startups(StartupId)` |
| 16 | **deals** | Stores investment deals between investors and startup projects. Tracks amount, equity percentage, payment method, confirmation status, and blockchain transaction hash. <br> - Primary keys: `DealId` <br> - Foreign keys: `InvestorId` → `investors(InvestorId)`, `ProjectId` → `projects(ProjectId)` |
| 17 | **nftrecords** | Stores NFT records minted for completed deals on the blockchain. Each record links a deal to a unique token with ownership and validity information. <br> - Primary keys: `NFTRecordId` <br> - Foreign keys: `DealId` → `deals(DealId)` |
| 18 | **bookings** | Stores consulting session bookings made by users (customers) with advisors. Includes time slot, price, and booking status. <br> - Primary keys: `BookingId` <br> - Foreign keys: `AdvisorId` → `advisors(AdvisorId)`, `CustomerId` → `users(Id)` |
| 19 | **wallets** | Stores digital wallets for users within the platform. Each wallet has a balance, currency type, and active status. <br> - Primary keys: `WalletId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 20 | **transactions** | Stores platform-level financial transaction records for users. Tracks amount, transaction type, status, and timestamp. <br> - Primary keys: `TransactionId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 21 | **subscriptions** | Stores user subscriptions to service packages. Tracks subscription period (start/end date) and status. <br> - Primary keys: `SubscriptionId` <br> - Foreign keys: `PackageId` → `packages(PackageId)`, `UserId` → `users(Id)` |
| 22 | **actionlogs** | Stores audit logs of actions performed by users in the system. Records the action type, affected entity type and ID, and timestamp. <br> - Primary keys: `ActionLogId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 23 | **posts** | Stores public posts/announcements created from approved connection requests (requires both startup and investor approval before publishing). <br> - Primary keys: `PostId` <br> - Foreign keys: `ConnectionRequestId` → `connectionrequests(ConnectionRequestId)` |
| 24 | **chatsessions** | Stores chat sessions initiated within a booking between an advisor and a customer. Tracks open/closed state and session duration. <br> - Primary keys: `ChatSessionId` <br> - Foreign keys: `BookingId` → `bookings(BookingId)` |
| 25 | **chatmessages** | Stores individual chat messages exchanged within a chat session. Each message is linked to a sender and a session. <br> - Primary keys: `ChatMessageId` <br> - Foreign keys: `ChatSessionId` → `chatsessions(ChatSessionId)`, `SenderId` → `users(Id)` |
| 26 | **consultingreports** | Stores formal consulting/meeting reports generated after a completed booking session. Includes meeting details, purpose, content, and decisions made. <br> - Primary keys: `ConsultingReportId` <br> - Foreign keys: `BookingId` → `bookings(BookingId)` |
| 27 | **reviews** | Stores reviews and ratings submitted by users for advisors after consulting sessions. <br> - Primary keys: `ReviewId` <br> - Foreign keys: `AdvisorId` → `advisors(AdvisorId)`, `ReviewerId` → `users(Id)` |
| 28 | **packages** | Stores service subscription packages available on the platform, including name, description, price, and duration. <br> - Primary keys: `PackageId` <br> - Foreign keys: _(none)_ |
| 29 | **wallettransactions** | Stores individual transaction records within a wallet (deposits, withdrawals, payments, etc.) with type and status tracking. <br> - Primary keys: `WalletTransactionId` <br> - Foreign keys: `WalletId` → `wallets(WalletId)` |
| 30 | **withdrawrequests** | Stores user withdrawal requests from their platform wallet. Tracks requested amount and approval status. <br> - Primary keys: `WithdrawRequestId` <br> - Foreign keys: `WalletId` → `wallets(WalletId)` |
| 31 | **notifications** | Stores in-app notifications sent to users. Tracks message content, read/unread status, and creation timestamp. <br> - Primary keys: `NotificationId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 32 | **blockchainproof** | Stores blockchain transaction proof records for verified documents. Links a document to its on-chain transaction hash and verification status. <br> - Primary keys: `BlockchainProofId` <br> - Foreign keys: `DocumentId` → `documents(DocumentId)` |
| 33 | **refresh_tokens** | Stores JWT refresh tokens issued to users for session management. Supports token rotation, revocation tracking, and IP recording. <br> - Primary keys: `RefreshTokenId` <br> - Foreign keys: `UserId` → `users(Id)` |
| 34 | **startup_followers** | Many-to-many join table representing users following startups. Records the follow timestamp. <br> - Primary keys: `UserId`, `StartupId` (composite) <br> - Foreign keys: `UserId` → `users(Id)`, `StartupId` → `startups(StartupId)` |
| 35 | **user_reports** | Stores reports filed by users against other users (e.g., fraudulent behavior). Tracks reporter, reported user, reason, evidence, and review status. <br> - Primary keys: `ReportId` <br> - Foreign keys: `ReporterId` → `users(Id)`, `ReportedUserId` → `users(Id)` |
